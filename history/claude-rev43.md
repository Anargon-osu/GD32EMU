# R43 - Claude Opus 5.5 (Anthropic), 2026-11-10

Revision numbers are the anargons-deco640-tools project's; its full R43 record is that project's
`history/claude-rev43.md`.

- **`P.WindowWidth()`** (new): the console window's visible columns, or -1 when output is not a console window
  (piped, tests). anargons-deco640-tools uses it to ask the user to zoom out when the window is narrower than its
  96-column screens (Anargon's request). Nothing else in the emulator changed.
